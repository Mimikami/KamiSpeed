功能特性

免 root

基于虚拟容器技术，游戏跑在 KamiSpeed 自己的进程里，不改系统、不刷机。

1x ~ 20x 实时变速

拖动滑杆即时生效，时间轴全程连续不回跳，对局节奏稳定。

悬浮调速面板

游戏内悬浮面板 / 半圆小球，随时调速、开关、± 微调。

兼容渠道 SDK

访客 Service / 自广播进程内托管，U8 / TFY 等渠道登录可正常完成。

快捷启动

收藏常用游戏，一键以当前倍率启动。

开源 GPL-3.0

源码完全开放，欢迎 Star / Fork / PR。

快速上手

  1. 下载并安装 APK（首次打开按提示允许悬浮窗权限）
  2. 打开 KamiSpeed，勾选开关并拖动滑杆设置倍率
  3. 点「＋ 添加」把游戏加到主面板，点击启动
  4. 游戏内通过悬浮面板实时调速；✕ 收成小球，点小球展开
